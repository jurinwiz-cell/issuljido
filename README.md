## 실행 · 배포

- 그냥 열기: `index.html`을 브라우저로 열면 됩니다(파일 더블클릭, `file://`에서도 저장 기능 동작).
- GitHub Pages: 저장소 루트(또는 `/docs`)에 `index.html`을 올리고 Settings → Pages에서 브랜치를 지정하면 바로 배포됩니다.

## 화면

1. **동네 기업·솔루션 (91곳 · 105건)** — 분야 칩, 동네·기관유형·비용 필터, 키워드 검색, 광명시 19개 동 SVG 지도(동 클릭 = 필터, 마우스 오버 = 동별 기업·솔루션 수), 카드 목록, 기업 상세 모달(소개·해결 문제·서비스 내용·해봄 원문 링크).
2. **시민 문제·매칭 (122건)** — 분야 필터, 검색, 적합 솔루션 수 표시, 「관련 기업 찾기」로 해당 분야 기업·솔루션 화면으로 이동.
3. **단골·상점 제보** — 정보 제공자(단골고객/상인) 관점의 데모 등록 폼. `localStorage`에 저장되어 목록에 즉시 반영되고, JSON으로 내보내 회의 자료로 쓸 수 있습니다.

## 상점주 설문 (`survey.html`)

동네 가게 사장님이 **카톡 링크로 바로 열어** 응답하는 모바일 우선 설문입니다. 로그인·앱 설치·외부 CDN 없이 이 파일 하나로 동작합니다.

- **3단계 · 8문항** — ① 가게 기본 정보(상호·업종·19개 행정동·단골층·방문 시간대·손님 한마디) ② 5~6주 실증 참여 의향(단골 혜택·이웃 가게 추천/안내문·걱정되는 점) ③ 홍보·카톡 도우미(대표 메뉴·소개글/사진 보정 희망)
- **모르면 비워두기** — 어떤 문항도 필수로 막지 않고, 결과 요약에는 `미응답`으로 표시됩니다. ‘잘 모르겠어요 / 아직 미정 / 특별히 없음’은 다른 선택과 함께 고를 수 없게 처리했습니다.
- **카톡 `ChatGPT for Kakao` 도우미** — 3단계에 접이식 카드. 상점주용 프롬프트 원클릭 복사 + ChatGPT 결과 붙여넣기 칸이 있고, 붙여넣은 글은 요약과 JSON에 함께 담깁니다.
- **결과 화면** — 설문 요약 카드 미리보기, `📋 카톡 전송용 요약 복사`(실패 시 직접 복사 패널), `💾 응답 파일(JSON) 저장`, `✨ 예시 채우기`, `초기화`.
- **호환성** — `localStorage`는 모두 `try/catch`(사생활 모드·샌드박스에서도 동작), 날짜는 `toISOString()` 대신 로컬 시각 포맷, 클립보드는 `navigator.clipboard` → `execCommand` → 직접 복사 패널 순서로 대체.
- 작성 중 내용은 브라우저에만 임시 저장되고, 응답은 JSON 파일로 내려받아 운영팀에 전달합니다(서버 전송 없음).

```bash
python3 preview_survey.py   # 미리보기 캡처
python3 test_survey.py      # Playwright 검증 (111개 항목)
```
