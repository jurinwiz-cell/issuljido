# 있을지도 — 광명 동네 기업·단골상점·시민문제 연결 리빙랩

광명시 시민참여 소셜리빙랩 6팀(C-2) 「있을지도」의 시연용 웹앱입니다. 외부 빌드 없이 정적 파일 두 개로 동작합니다.

- 지도 웹앱: <https://jurinwiz-cell.github.io/issuljido/>
- 상점주 설문: <https://jurinwiz-cell.github.io/issuljido/survey.html>

## 이 저장소에 있는 것

| 파일 | 설명 |
| --- | --- |
| `index.html` | 지도 웹앱 단일 HTML (데이터·스타일·스크립트 내장) |
| `survey.html` | 상점주 모바일 설문 단일 HTML (8문항·3단계) |
| `.nojekyll` | GitHub Pages Jekyll 처리 비활성화 |

## 지도 웹앱 (`index.html`)

- **도로 지도** — Leaflet 1.9.4(파일 내장) + OpenStreetMap 타일. 동 경계, 동 대표 좌표 기관 마커, 단골 참여 상점 마커를 함께 표시합니다.
- **동네 요약 지도** — 광명시 19개 행정동 SVG. 타일을 못 불러오거나 오프라인·라이브러리 부재 시 자동으로 전환되고, 지도 카드의 `도로 지도 / 동네 요약` 버튼으로 직접 바꿀 수도 있습니다.
- **⭐ 단골 참여 상점 (3)** — 샘플 상점 3곳을 `[샘플]` 배지로 표시합니다. 카드에 도로명 주소와 전화번호(`tel:`)가 있고, 상세 화면에서 주소 복사·전화 걸기·카카오맵/네이버지도 길찾기 링크를 제공합니다.
- **동네 기업·솔루션 91곳 / 시민 문제 122건** — 분야·동네·유형·비용 필터, 검색, 상세 모달.
- **단골·상점 제보** — 가게 주소·전화(선택)를 포함해 등록하고, 브라우저(`localStorage`)에만 저장하며 JSON으로 내보냅니다.

## 데이터와 표기

- 기업·기관 91곳, 해결 솔루션 105건, 시민 문제 122건: 해봄(<https://haebom.it>) 공개 API 2026-11-19 11:16 수집 스냅샷.
- 해봄 기관 위치는 **동 단위 대표 좌표**입니다(도로명 주소·연락처 비공개).
- 단골 참여 상점 3곳은 **`[샘플]`**입니다. 주소·좌표는 광명시 실제 도로명 주소(카카오 지오코딩 확인)이고, 상호·전화·메뉴·혜택은 시연용 예시 값입니다.
  - `[샘플]` 카페 온도 — 철산3동, 경기도 광명시 철산로 15, 1층
  - `[샘플]` 동네책방 마주 — 하안2동, 경기도 광명시 범안로 1049, 1층
  - `[샘플]` 소하 반찬부엌 — 소하2동, 경기도 광명시 서면로 28, 1층
- 지도 타일: © OpenStreetMap 기여자. 타일 요청 실패 시 동 지도로 폴백합니다.

## 상점주 설문 (`survey.html`)

- 3단계·8문항, 로그인·앱 설치 없이 카톡 링크로 응답. 1단계에 **가게 주소(도로명)·전화번호** 입력란(선택)이 있습니다.
- 모르는 항목은 비워둘 수 있고, 결과 요약에는 `미응답`으로 표시됩니다.
- 결과는 요약 복사(카톡 전송용)와 JSON 파일로 받을 수 있으며, 서버로 전송되지 않습니다.

## 개발 메모

빌드 스크립트·테스트·원본 조각(`parts/`)은 저장소에 포함하지 않았습니다. 배포 파일은 이 두 HTML이며, 수정 후 다시 올리면 Pages에 바로 반영됩니다.
